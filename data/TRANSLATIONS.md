# Переводы

Языки сайта: `ru`, `en`, `de`. Читатель выбирает язык кнопками RU / EN / DE в меню
(выбор запоминается, ещё можно дать ссылку с `?lang=en`).

## Стихи

Перевод каталога лежит рядом с оригиналом, к имени добавляется код языка:

```
data/poetry/salvia.txt       ← оригинал
data/poetry/salvia.en.txt    ← английский перевод
data/poetry/salvia.de.txt    ← немецкий перевод
```

Формат тот же, что у оригинала. Стих из перевода находит свой оригинал по `id:`,
поэтому `id` копируется из оригинала **без изменений**. `date` можно не писать, она берётся из оригинала.

```
=== poem ===
id: 2018-06-24-обойди-меня-за-девять-верст
title: Go around me by nine versts

Go around me by nine versts,
...
```

- Переводить можно постепенно: в файле достаточно тех стихов, которые уже готовы.
  Остальные читатель увидит в оригинале с пометкой «not translated yet».
- У переведённого стиха есть кнопка «Original», которая показывает оригинал.
- Порядок стихов в файле перевода не важен.
- Комментарии общие для всех языков: они привязаны к `id` стиха.

## Названия и описания каталогов

В `data/poetry/catalogs.json` у каталога можно добавить блок `i18n`:

```json
{
  "id": "salvia",
  "label": "Сальвии",
  "desc": "Первая половина 2018.",
  "href": "./poems.html?cat=salvia",
  "i18n": {
    "en": { "label": "Salvias", "desc": "First half of 2018." },
    "de": { "label": "Salbei", "desc": "Erste Hälfte 2018." }
  }
}
```

Чего нет в `i18n`, показывается по-русски.

Если каталог написан не по-русски, укажи язык оригинала: `"lang": "en"`.
Тогда перевод будет искаться для всех остальных языков, включая `ru` (`<cat>.ru.txt`).

## Тексты интерфейса

Меню, кнопки, сообщения: всё в `assets/i18n.js`, по словарю на язык.
В HTML текст помечается `data-i18n="ключ"`, а русский текст остаётся в разметке как запасной вариант.
