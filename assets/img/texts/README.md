# Что высыпается из книг (страница «Тексты»)

Когда книга падает со стола, из неё вылетают картинки из папки её раздела
и пожелтевшие листки бумаги (листки рисуются сами, их сюда класть не надо).

Папки разделов:

| папка        | книга               |
|--------------|---------------------|
| `stories`    | Рассказы            |
| `tales`      | Сказки              |
| `repatriate` | Записки репатрианта |
| `dreams`     | Сны                 |
| `chatter`    | Болтовня            |
| `other`      | Другое              |

## Какие картинки класть

- **Формат:** PNG с прозрачным фоном.
- **Имена:** `1.png`, `2.png`, `3.png`, ... подряд, без пропусков. Сайт перебирает
  номера по порядку и останавливается на первом отсутствующем, поэтому `1, 2, 4`
  покажет только первые две. Не больше 40 штук в папке.
- **Размер:** примерно 128–256 px по длинной стороне. На экране они будут
  примерно 30–55 px, так что крупнее не нужно. Лучше до 50 КБ на картинку.
- **Обрезка:** почти без пустых полей вокруг предмета. Картинка крутится вокруг
  своего центра, поэтому предмет лучше ставить по центру.
- Листья, веточки, засушенные цветы, лепестки, обрывки бумаги, билетики — что угодно.

Сейчас в каждой папке лежат по 4 временные картинки. Их можно просто заменить
своими или удалить и положить новые под теми же номерами.
